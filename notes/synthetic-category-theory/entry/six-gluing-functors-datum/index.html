Definition 19.6.10. A six gluing functors datum is a diagram of stable categories of the form in which all functors are exact, with the following properties.

  • (i) We have \(i^*\circ j_! = 0\).

  • (ii) Both functors \(j_!\) and \(i_*\) are fully faithful.

  • (iii) The functor \(j^*\) is right adjoint to \(j_!\) and left adjoint to \(j_*\).

  • (iv) The functor \(i^*\) is left adjoint to \(i_*\).

  • (v) The pair \((j^*,i^*)\) is jointly conservative: for any object \(x : X^\simeq\), we have \(x= 0\) if and only if \(j^*(x)=0\) and \(i^*(x)=0\).
