Lemma C.3.

Let \(T\) be a locally small category, and let \(D \subseteq C \subseteq T\) be essentially small full subcategories. If \(D\) is dense in \(T\), then so is \(C\).

Proof
Write \(i_D\colon D \hookrightarrow T\), \(i_C\colon C \hookrightarrow T\) and \(j\colon D \hookrightarrow C\) for the inclusions, so that \(i_D^* \simeq j^* \circ i_C^*\). Since \(\An\) admits small limits, the restriction functor \(j^*\colon \PSh(C) \to \PSh(D)\) admits a right adjoint \(j_*\), given by right Kan extension. Let \(\eta\colon \id \to j_*j^*\) denote the unit.

Claim.

For every \(Y \in T\), the map \(\eta_{i_C^*Y}\colon i_C^*Y \to j_*i_D^*Y\) is an isomorphism.

It suffices to check this after evaluation at every object \(c \in C\). By the Yoneda lemma and the adjunction \(j^* \dashv j_*\), the evaluation at \(c\) is identified with the map
\[\Hom_{\PSh(C)}\bigl(h_C(c), i_C^*Y\bigr) \longrightarrow \Hom_{\PSh(D)}\bigl(j^*h_C(c), j^*i_C^*Y\bigr)\]
induced by \(j^*\). Since \(C\) is a full subcategory of \(T\), we have \(h_C(c) \simeq i_C^*(c)\), so \(j^*h_C(c) \simeq i_D^*(c)\) and \(j^*i_C^*Y \simeq i_D^*Y\). Precomposing with the Yoneda isomorphism \(\Hom_T(c,Y) \simeq \Hom_{\PSh(C)}(h_C(c), i_C^*Y)\), the displayed map becomes the map
\[\Hom_T(c,Y) \longrightarrow \Hom_{\PSh(D)}\bigl(i_D^*c, i_D^*Y\bigr)\]
induced by \(i_D^*\). It is an isomorphism because \(D\) is dense. This proves the claim.
Now let \(X, Y \in T\). Consider the composite
\[\Hom_T(X,Y) \xrightarrow{\;i_C^*\;} \Hom_{\PSh(C)}\bigl(i_C^*X, i_C^*Y\bigr) \xrightarrow{\;(\eta_{i_C^*Y})_*\;} \Hom_{\PSh(C)}\bigl(i_C^*X, j_*i_D^*Y\bigr) \simeq \Hom_{\PSh(D)}\bigl(i_D^*X, i_D^*Y\bigr).\]
By construction of the adjunction isomorphism, the composite of the last two maps is induced by \(j^*\). The total composite is therefore the map induced by \(i_D^* \simeq j^*i_C^*\), which is an isomorphism because \(D\) is dense. The second map is an isomorphism by the claim. Hence the first map is an isomorphism, so \(C\) is dense.
